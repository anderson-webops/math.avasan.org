## Scratch coordinate game

The optional coordinate-learning activity uses Scratch project `1367463968`,
currently titled “Bug Eater remix” and published by Scratch user `Avasan2` as a
remix of project `297831461`. The project is hosted and executed by Scratch; it
is not copied into this repository or relicensed under the root ISC license.

The live project can change or become unavailable without a Math release. Its
iframe is created only after a student explicitly opens the activity and is
removed when the dialog closes. Scratch and its service providers receive the
ordinary network request needed to load the third-party player. No Math
account, graph content, course state, or first-party analytics event is passed
to the player.
